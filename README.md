A Modpack for our server Earth Live 3. It is focused around the progression through different tech mods — from Create to Draconic Evolution, over Mekanism and AE2. We have all the big mods you know! Everything is connected via custom recipes and tons of quests.

There are even more quests and custom recipes to come. I plan on adding new content for our server for quite a while.
